# Swale Homebrew tap

Installs the [Swale CLI](https://docs.swale.io/reference/install-cli) on macOS and Linux:

```sh
brew install swaleio/tap/swale
```

Installing by the full name trusts this one cask, not the whole tap. Upgrade with `brew upgrade swale`; `brew uninstall --zap swale` also removes `~/.swale`, where the CLI keeps its accounts and credentials.

Other platforms, the install script and verifying a download: [Install the CLI](https://docs.swale.io/reference/install-cli).
